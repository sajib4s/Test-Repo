# TestProject

Node.js workspace for TypeScript and Next.js work. Author: Ali Reza Khan.

## Stack

- Node.js
- TypeScript
- Next.js
- `dotenv` for environment variables

## Setup

```bash
npm install
```

Create a `.env` file for secrets. Do not commit it. A `.env.example` is fine to share.

## Scripts

```bash
npm test
```

No app scripts are defined yet. Add Next.js (`dev`, `build`, `start`) when the app is initialized.

app/           routes, layouts, pages, API
